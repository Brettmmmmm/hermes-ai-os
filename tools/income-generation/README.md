## Quick-Start: What To Do Right Now

### If you need income this month:

1. Read `target-companies.md` — pick 5 companies in the "Priority Order" section
2. Read `cv-tailoring-guide.md` — tailor your CV for your top pick
3. Send 5 cold outreaches using the template in `target-companies.md`
4. Post 2 LinkedIn posts from `linkedin-content.md` this week
5. Send `personal-portfolio.md` (or a shortened version) to anyone who asks what you do

### If you're pitching a consulting engagement:

1. Copy `proposal-template.md`
2. Fill in the first 4 sections (Executive Summary, Current State, Proposed Solution, Technical Approach)
3. Customise the deliverables and timeline
4. Use the tiered pricing from the template (adjust for engagement size)
5. Send. Follow up in 5 days if no response.

When you invoke the skill via Hermes, it:

## Design Principles

1. **Actionable over theoretical.** Every file should tell you what to DO, not just what to think.
2. **Brett's voice.** Not corporate. Not recruiter-speak. Direct, technical, confident.
3. **Specific over generic.** "Six-class DSCP model" > "QoS best practice." "Equinix LD4" > "a colocation facility."
4. **Maintainable.** Structured files (YAML matrix, template variables) so you can update data without rewriting documents.
5. **Respect the rarity.** CCIE QoS is genuinely rare. Don't be shy about it. It's not arrogance if it's true.
