# Hermes AI OS Layer

Hermes is the conversational and orchestration layer of your personal AI OS.

It provides:

- **Personality packs** for different roles (architect, coder, analyst, operator, researcher)
- **Skill routing** for diagnostics, remediation, codegen, planning, and summarisation
- **Model routing** across local Ollama models and optional cloud models
- **Deterministic policy layers** that enforce structure, safety, and reproducibility
